🚀 快速部署方案

🌐

方案1: GitHub Pages（推荐）

完全免费，全球CDN加速，支持自定义域名

步骤：

  1. 在 GitHub 创建新仓库（public）
  2. 上传整个项目文件夹
  3. 仓库 Settings → Pages → 选择 main 分支
  4. 几分钟后访问 https://你的用户名.github.io/仓库名
查看详细教程 →
⚡

方案2: Netlify Drop

拖拽部署，30秒上线，自动HTTPS

步骤：

  1. 访问 app.netlify.com/drop
  2. 注册/登录账号（支持GitHub登录）
  3. 直接拖拽整个项目文件夹到页面
  4. 自动生成链接 https://随机名.netlify.app
立即部署 →
▲

方案3: Vercel

极速部署，边缘网络，自动优化

步骤：

  1. 访问 vercel.com
  2. 使用GitHub登录
  3. Import Project → 选择仓库
  4. 自动检测并部署，生成 .vercel.app 域名
前往部署 →
☁️

方案4: Cloudflare Pages

免费无限流量，全球300+节点

步骤：

  1. 访问 dash.cloudflare.com
  2. Pages → Create a project
  3. 连接GitHub仓库或直接上传
  4. 部署完成，获得 .pages.dev 域名
开始部署 →

💻 本地运行（快速测试）

方法1: Python（推荐）

python -m http.server 8000

然后访问 http://localhost:8000

方法2: Node.js

npx http-server -p 8000

方法3: VS Code

安装 Live Server 插件，右键 index.html → Open with Live Server
