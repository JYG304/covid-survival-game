# 打工人抗疫日记

2022 年，朝阳里一间 loft 出租屋。横板走、进门、做饭、核酸、上班。出门次数有限，健康码会黄会红，阿花会饿。

**在线玩：** https://jyg304.github.io/covid-survival-game/

本地：仓库根目录起一个静态服务即可。

```bash
python -m http.server 8000
```

打开 `http://localhost:8000`。Windows 也可以双击 `启动游戏.bat`。

## 操作

- A / D 或方向键走路，点地面也能走
- E 或空格、点建筑/人交互
- 手机面板在画面右上角

## 现在能玩什么

- 六个街区（生活 / 商业 / 夜巷 / 医疗 / 办公 / 滨江），店面和楼按真实层数进
- 出租屋：冰箱会过期，卫生间能洗手洗澡通马桶，垃圾和砂盆要处理，能量体温、做抗原
- 每天三条硬任务，从家里出门会扣次数
- 黄码进不了写字楼和商场；红码基本只能待在家
- 工位打卡、推拿馆排班、抢菜、团购这些还在

纯前端，没有后端。代码在 `src/`。
