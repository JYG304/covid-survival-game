🚀 如何运行
------------------------------------------

方法1: 使用 Python (推荐)
  python -m http.server 8000
  然后访问: http://localhost:8000

方法2: 使用 Node.js
  npx http-server -p 8000
  然后访问: http://localhost:8000

方法3: 使用 PHP
  php -S localhost:8000
  然后访问: http://localhost:8000

⚠️ 注意：必须通过 HTTP 服务器运行，不能直接双击打开 HTML！
原因：ES6 模块需要通过 HTTP 协议加载。

------------------------------------------
🎮 游戏控制
------------------------------------------

桌面端:
  A/D 或方向键 - 左右移动
  E 或空格键  - 与附近物体交互

移动端:
  使用底部虚拟按钮

🔧 如何添加新功能
------------------------------------------

1. 添加新地标物体
   → 编辑 src/data/landmarks.js

2. 添加新动作
   → 编辑 src/systems/actionSystem.js

3. 添加新状态
   → 编辑 src/data/gameState.js

4. 修改渲染
   → 编辑 src/game/renderer.js

详细说明请查看:
  - README.md (项目文档)
  - src/DEVGUIDE.js (开发指南)

🐛 遇到问题？
------------------------------------------

1. 页面空白
   → 检查是否通过 HTTP 服务器运行
   → 打开浏览器控制台查看错误信息

2. 模块加载失败
   → 确保 src/ 目录结构完整
   → 检查文件路径大小写

3. 功能不完整
   → 当前版本是核心系统重构版
   → 可运行原版 code_artifact.html 体验完整功能
